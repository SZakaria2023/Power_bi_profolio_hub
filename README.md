# Power BI & Data Analytics Portfolio

## Overview
This repository serves as a centralized index of my Business Intelligence and data analytics projects built in Microsoft Power BI. Each project is maintained in its own dedicated repository containing the source datasets, `.pbix` report file, DAX documentation, and visual previews.

## Featured Projects

### 1. Car Fleet Availability Management Solution
* **Repository:** [car_fleet_dashboard_project](https://github.com/SZakaria2023/car_fleet_dashboard_project)
* **Tools:** Microsoft Power BI, DAX, Power Query, Microsoft Excel
* **Summary:** A single-page interactive dashboard monitoring vehicle availability, operational status, and fleet distribution across depots and regions using a one-to-many data model (`VehicleID`) and time-filtered DAX measures to prevent duplicate log counts.
